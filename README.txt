RAÍZWEB - PRIMERA VERSIÓN DE PÁGINA WEB

ARCHIVOS
- index.html: estructura y contenido de la página.
- styles.css: colores, tipografía, distribución y adaptación a celular.
- script.js: menú desplegable para pantallas pequeñas.

CÓMO VER LA PÁGINA
1. Descomprime la carpeta.
2. Abre index.html en Google Chrome, Safari o Firefox.
3. Para editar, abre los archivos con un editor de código.

CÓMO PUBLICAR EN GITHUB PAGES
1. Crea un repositorio público llamado EXACTAMENTE usuario.github.io
   (reemplaza "usuario" por tu nombre de usuario de GitHub).
2. Sube index.html, styles.css y script.js a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
4. Guarda y espera a que GitHub publique el sitio.
5. Tu dirección será https://usuario.github.io

PRUEBAS PARA EL EXAMEN
- Abre el enlace publicado en una ventana privada o sin iniciar sesión.
- Prueba los enlaces del menú y el botón "Conoce nuestras bolsas".
- Reduce el ancho de la ventana para revisar la versión móvil.
- Comprueba que el menú móvil se abra y se cierre.

NOTA
El diseño es una primera versión escolar inspirada en el concepto RaízWeb:
bolsas de origen vegetal, consumo consciente, tonos verde oscuro y beige.
Puedes personalizar los textos y datos de contacto para que coincidan con tu prototipo.
La tipografía usa Google Fonts, por lo que requiere conexión a internet para cargarse.
